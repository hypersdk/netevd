# Hook: manager / NetworkManager

## Purpose

`activated.d`, `disconnected.d`, and `manager.d` cover NetworkManager device and manager state.

## When to use it

Hosts where NM is the primary backend (`system.backend: NetworkManager`).

## How to get there

Matching directories under `/etc/netevd/`.
